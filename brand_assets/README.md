# brand_assets

Source brand files. Always check here before designing; real assets replace placeholders.

## Logos

| File                      | Use                                         |
| ------------------------- | ------------------------------------------- |
| `logo-wordmark.png`       | Primary logo on light backgrounds           |
| `logo-mark.png`           | Icon only (favicon, small spaces)           |
| `logo-wordmark-white.png` | On brand-blue / dark backgrounds            |
| `logo-mark-white.png`     | Icon on brand-blue / dark backgrounds       |

Trimmed copies used by the site live in `public/brand/`. App icons (`app/icon.png`,
`app/apple-icon.png`) are generated from `logo-mark.png`.

## Colors

| Name       | Hex       |
| ---------- | --------- |
| Navy       | `#0D2847` |
| Deep Blue  | `#0A2472` |
| Royal Blue | `#123499` |
| Brand Blue | `#2B59D8` |
| Light Blue | `#6E93F0` |
| Grey Text  | `#5B6573` |
| Card       | `#F3F1EC` |
| Background | `#FAF9F6` |

Brand gradient: `#6E93F0` → `#2B59D8`.

## Rules

- Light backgrounds with gradient accents. No full dark theme.
- No purple outside the logo.
- White text only on `#2B59D8` or darker (contrast).
